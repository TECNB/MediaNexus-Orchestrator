# Adult 超时放弃与单项目录清理

用户批准用实测流程替代 df0b1fb：Adult 下载达到2分钟默认时限后，一次取消上游任务、一次删除该下载项专属临时目录，记录失败及每个清理操作结果，释放本地占用；不持续后台查询、不因终态历史 OFFLINE_UNRESOLVED 重建局部隔离或全局暂停。当前仍活动的重启任务保持中断处理，不重发未知提交。

实测依据：工作区 diagnostics/cancel-delete-timing-2026-11-28/report.md，四样本取消+删除0.976–1.552秒。本次采用取消/清理合计5秒请求预算，异常原样记录，不冒称远端绝对停止。临时目录必须为批次目标的唯一直接子目录，禁止删除共享日期目录、成功资源或已发布文件。

实现范围：复用共享 OfflineIngestScheduler 和 OpenListClient，通过实际使用的可放弃下载 interface 区分 Adult 与电影/剧集。电影/剧集保留原取消核实和恢复行为；不改变其换源规则。Adult查询和轮询不得把截止时间拖延至默认120秒请求超时。父批次失败数只记一次，失败详情持久化，批次可继续并保留成功结果。删除 df0b1fb 的局部隔离代码和专用测试，用启动恢复与超时行为回归替代。

已批准测试接口：现有调度器 enqueueBatch、Adult任务入口/启动恢复及OpenList HTTP操作。测试覆盖超时后后续任务继续、清理失败仍结束且记录、只删专属目录、批次计数与成功项保留、旧终态错误不再阻塞。按项目约定只运行定向回归，一次限定审查。

生产：先API只读核对旧失败项和当前任务，不删除整个日期目录。仅在无活动业务写入窗口执行原deploy.sh，核对版本/health与真实独立超时样本。没有安全窗口则交付已验证代码并报告发布阻塞，不擅自取消其他任务。保留主工作区dirty修改。
